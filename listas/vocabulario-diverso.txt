# Vocabulário avulso
#
# Palavras soltas pedidas à parte, sem tema gramatical único. As que já
# estavam cobertas por outra lista ficaram de fora daqui: Ele, ela, Nós
# (pronomes-pessoais.txt); Meu, Seu, Dele, Dela, Próprio (pronomes-possessivos.txt);
# Bem-vindo, Bom dia, Boa tarde, Prazer, Obrigado, Nome (saudacoes.txt).
#
# CELULAR e PESSOA têm dois verbetes cada no INES (sentidos diferentes, não
# ambiguidade de busca):
#
#     celular   telefone "de botão" antigo / smartphone com texto
#     pessoa    ser humano / indivíduo, sujeito
#
# "Não tenho" vira frase: TER tem verbete, mas a negação em si não é um
# verbete à parte no INES.

tenho
não tenho
não quero
não gosto

amigo
cinema
cidade
celular
irmão

cachorro
gato
macho
fêmea

pessoa
masculino
feminino

# TELEFONE não existe no INES em forma nenhuma — só ORELHÃO (TELEFONE PÚBLICO)
# e TELEFONISTA. Lacuna real, apesar de CELULAR existir. Pergunte na aula.
# ALUGUEL tem dois verbetes, com sentidos distintos.
