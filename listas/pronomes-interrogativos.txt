# Pronomes interrogativos
#
# QUAL, QUEM, COMO e QUANDO têm mais de um verbete no INES porque o sinal
# muda com o contexto da pergunta — não é ambiguidade da busca, é o
# dicionário registrando sinais diferentes:
#
#     qual    identificar um local / diferenciar um local do outro / preferência
#     quem    identificar dono / identificar autor / identificar ou nominar alguém
#     como    "do mesmo modo" / pergunta "de que modo?"
#     quando  época de um acontecimento / data de um acontecimento passado
#
# QUÊ cobre o "o que" falado no dia a dia (INES só tem a forma sem "o").
#
