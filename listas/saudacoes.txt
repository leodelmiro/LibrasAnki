# Cumprimentos
#
# Não existe assunto "saudações" no INES: os 21 assuntos de lá são categorias
# concretas (ALIMENTO, ANIMAL, CORPO...) e 64% dos verbetes caem em "NENHUM".
# Por isso este agrupamento é manual.
#
# As linhas com "=" forçam tratamento como palavra: faltam tanto no INES quanto
# no Spread the Sign, os dois acervos consultados quando estas listas foram
# montadas, o que sugere que se sinaliza BOM + DIA em sequência.
#
# Ressalva: o dicionário do VLibras (23.432 sinais) registra BOM_DIA, BOA_NOITE
# e DE_NADA como sinal único. Isso pode ser conveniência de renderização do
# avatar, não prova de item lexical distinto — mas basta para não afirmar que
# "não existem em dicionário nenhum". São as primeiras a perguntar na aula.
#
# Os compostos não ficam sem vídeo: o card mostra os componentes em sequência
# (BOA + TARDE), montados a partir da tabela COMPOSTOS em gerador.py. Só "ótimo"
# fica com falta-video, porque não é composto — é lacuna mesmo.
#
# PRAZER1 está aqui como vocabulário ("alegria; satisfação"), NÃO como o
# cumprimento. "Prazer em conhecer você" se sinaliza GOSTAR + CONHECER + VOCÊ,
# sem passar por PRAZER — está em frases-apostila.txt. Os outros dois verbetes
# ficam de fora de propósito: PRAZER2 é sinônimo de PRAZER1 e PRAZER3 é
# "satisfação sexual".
